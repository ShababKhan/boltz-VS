## 2024-06-18 - Optimized MMCIF and PDB parsing
**Learning:** Calling `re.sub()` inside an inner loop that iterates over potentially tens of thousands of atoms is a performance anti-pattern. `re.sub()` implicitly compiles the regex string every time, which has measurable overhead.
**Action:** When a regular expression is needed for data parsing or formatting inside high-frequency loops (like processing atom or residue records), pre-compile the regex pattern at the module level (e.g. `RE_DIGIT = re.compile(r"\d")`) and use `RE.sub()` on the compiled object to avoid regex parsing overhead during iterations.
